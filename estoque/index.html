Como criar a chave de acesso (uma vez só)

1. Entra no GitHub → clica na sua foto de perfil (canto superior direito) → Settings
2. Desce até Developer settings (no fim do menu à esquerda)
3. Clica em Personal access tokens → Fine-grained tokens
4. Generate new token
5. Em "Repository access", escolha Only select repositories e marca só o repositório do site
6. Em "Permissions → Repository permissions", acha Contents e muda pra Read and write
7. Clica em Generate token e copia a chave (começa com github_pat_...) — cola ela aqui em cima, no campo "Chave de acesso"
